Device-specific installation guides
  • Samsung: Settings → Biometrics and security → Install unknown apps
  • Xiaomi: Settings → Apps → Manage apps → Install unknown apps
  • OnePlus / OPPO: Settings → Security → Install unknown apps
  • Huawei: Settings → Security → More settings → Install apps from external sources
  • Android 13+: You will see a prompt to allow installation from your browser — tap Allow.
  • Amazon Fire Tablet: Settings → Security & Privacy → Apps from Unknown Sources (or Settings → Apps & Notifications → Special App Access → Install unknown apps). Toggle ON for the browser or file manager you are using.
Compatibility: This app requires Android 6.0 (Marshmallow) or higher, and Fire OS 6 or higher for Amazon Fire devices.
